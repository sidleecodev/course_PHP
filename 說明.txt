安裝XAMPP，這是PHP開發環境
網頁輸入127.0.0.1有看到XAMPP Apache的畫面，表示伺服器啟動成功
該網頁點選"phpmyadmin，左邊點"新增"來新增資料庫
（後面備註建議都要填寫，因為資料庫內容可能很龐大）

***欄位介紹***
primary key(PK)：主鍵，為索引鍵，值預設自動遞增，可以用主鍵搜尋來加快速度
CHAR：固定長度，例如長度設10就固定為10，實際長度不到10，所占空間也是10
VARCHAR：變動長度，根據實際長度決定所占空間，所以實際長度6就是10
CHAR的優勢：搜尋速度比VARCHAR快
輸入的字很多，就使用TEXT

***新增值***
>>操作介面
在主畫面上面標籤選擇"新增"，主鍵、timestamp不輸入
全部輸入完，按最下方"執行"即新增完畢

>>語法（不分大小寫，一般來說都用大寫；欄位名稱有分大小寫，文字、日期一定要加單引號''）
  INSERT INTO `member` (`id`, `userId`, `userName`, `createTime`) VALUES (NULL, 'A000000001', '測試一', current_timestamp()), (NULL, 'A000000002', '測試二', current_timestamp());
此情況來說，可以是：
  INSERT INTO `member` (`userId`, `userName`) VALUES ('A000000001', '測試一'), ('A000000002', '測試二');
或以下常用作法：
  INSERT INTO member (userId, userName) VALUES ('A000000001', '測試一'), ('A000000002', '測試二')

***匯出資料庫，備份常用做法(匯入就相當於還原資料)***
左邊點選要輸出的資料庫，上面標籤選擇"匯出"
中間選"自訂"
下面物件建立選項：
>>(打勾)加入 DROP TABLE / VIEW / PROCEDURE / FUNCTION / EVENT / TRIGGER 指令

***更改資料表的設定***
點欲修改的資料表，上面標籤選擇"操作"
底下就有選項可以調整（類似設定的功能）

**清空的方式**
清空資料表(TRUNCATE)：清空資料，結構留存，流水號會重置，所有資料一次全部刪除
Empty the table(DELETE FROM)：清空資料，結構留存，但流水號會接續先前的序號，留有log，且是一筆一筆刪除
刪除資料表(DROP)：刪除整張資料表，資料、結構都全部刪除
