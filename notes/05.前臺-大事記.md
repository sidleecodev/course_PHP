## 先分清前臺與後臺

| 項目 | 後臺（已學） | 本次前臺 |

## 1. 建立前臺大事記 View

新增：

```text
resources/views/front/milestone/list.blade.php
```

原筆記說所有前臺網頁都放在 front；這是本專案的 View 資料夾安排，並非把 Controller、CSS／JS 也搬到 resources/views/front。

來源：複製 **html/milestones.html 中 main 之間的內容**。原 HTML 未附，因此這份整理沒有可直接貼用的完整頁面。

| 要放的內容 | 處理 |
| --- | --- |
| 大事記頁面的 main 內部 | 放進此頁專屬內容 |
| 共用 head、導覽、頁尾等 | 後續由 front/layout.blade.php 管理，不在每頁重貼 |

先照老師建立檔案與取得模板；layout 雖記在第 4 步，真正套用時需先存在。引用與插槽要依原 HTML／老師後續程式核對，本筆記不自定義新的版型介面。

## 2. 建立前臺 Controller

在專案根目錄執行老師指令：

```bash
php artisan make:controller Front/FrontMileStoneController
```

產生：

```text
app/Http/Controllers/Front/FrontMileStoneController.php
```

類別名稱：FrontMileStoneController。namespace 應對應 App\Http\Controllers\Front。

老師要求加入 list()，但**原筆記沒有方法內容**。尚無查詢方式、排序、分類、分頁或傳入 View 的變數，不能把後臺 list() 的內容直接當成老師前臺實作。

## 3. 建立前臺路由

原路由補上分號：

```php
Route::get("milestone", [FrontMileStoneController::class, "list"]);
```

路由檔上方需能辨識類別；下列為對應引入補充：

```php
use App\Http\Controllers\Front\FrontMileStoneController;
```

| 部分 | 意思 |
| --- | --- |
| GET | 瀏覽器請求顯示頁面 |
| milestone | 公開網址路徑 /milestone |
| FrontMileStoneController::class | 指定前臺 Controller |
| list | 執行該類別的方法 |

此處不安排重新學習 Route 語法；新的重點是前後臺使用不同入口與畫面。單有路由與空白方法，尚不能保證大事記頁面正常顯示。
