## 2. 拆出側欄

1. 把 home.blade.php 全部內容複製到 layout.blade.php。
2. 從 layout 剪下完整 `<aside>...</aside>`，放到 menu.blade.php。
3. layout 原本側欄位置改成 `@include("admin.menu")`。

老師的局部示意：

```blade
<body class="admin-body">
    <!-- ===== 側欄 =====
        php的引入檔案方式有4種，include, include_once, require, require_once  
    -->
    @include("admin.menu")
    ...
    ...
</body>
```

`@include`：引入另一個 Blade 模板。
原碼的 `...` 是省略標記，不是要貼入網站的內容。

PHP 的 include／require 不完全相同：引入失敗時的處理不同；_once 表示避免重複引入。本例使用 Blade 的 @include。

## 5. 建立帳號列表控制器

終端機：
```bash

```

```php
<?php

namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use App\Models\Admin\Manager;
use Illuminate\Http\Request;

class ManagerController extends Controller
{
    public function list(){
        // get: 取得全部資料，也可以用all -> Manager::all();
        // 將取得的資料以$list變數儲存
        // 此處Manager是一個資料表，在app\Models\Admin\Manager.php
 	$list = Manager::paginate(10);
	/*
	    原本是指令是這個，但後續要做分頁(9.)，所以改為上面這個，括號內為幾筆為一頁
            $list = Manager::get();
	*/
        // compact: 將資料渲染到admin.manager.list這個網頁（此時list還沒創建）
        // compact("list"): 這個list為上一行的$list，兩個名稱要一樣
        return view("admin.manager.list", compact("list"));
    }
}
```

- `Manager` 是 Model，對應 manager 資料表。
- `paginate(10)`：每頁 10 筆，回傳分頁物件。
- `get()`／`all()`：取得資料集合，本身沒有 links()。
- `compact("list")`：建立含 list 鍵與 $list 值的陣列。
- `view(..., compact(...))`：將資料傳入指定模板，並回傳畫面。

### 11-2. 用 jQuery 發送 AJAX

以下含 Blade token 的 script 放在 .blade.php 中，不能原樣搬到普通外部 .js 檔。
先確認完整版 jQuery 已載入；layout 若已有，不要重複載入第二次。

```blade
<script src="https://code.jquery.com/jquery-4.0.0.min.js"></script>
<script>
    function checkAccount(){
        // $：jQuery的用法，$("#userId")：取得id="userId"這個欄位的資料
        // val()：值，$("#userId").val()：取得此資料的值
        // var可以用let
        var userId = $("#userId").val();
        // 先將id="msg"的文字清除，並寫進html
        $("#msg").html("");
        // 如果有輸入帳號（非空字串）
        if (userId != ""){
            // ajax：非同步傳輸，頁面可以先顯示，再等資料進來
            $.ajax({
                // 老師用"/manager/checkAccount"
                url:"/admin/manager/checkAccount",
                type:"post",
                // data：所有要送往後端的資料
                data:{
                    // 送到後端的名稱: 所輸入的帳號
                    userId: userId,
                    // 加上權杖
                    _token: "{{ csrf_token() }}"
                },
                success: function(msg){
                    // msg為自取名稱，是後端回傳的資料
                    // trim():去除左右空白
                    if(msg.trim() == "exist"){
                        // 在id="msg"中寫入html語法（前面清除了，這裡寫回來了）
                        $("#msg").html("<font color='red'>帳號已存在</font>");
                        $("#userId").focus();
                    }
                }
            });
        }
    }
</script>
```

| 寫法 | 用途 |
| --- | --- |
| $("#userId").val() | 取得前端欄位值 |
| $("#msg").html("") | 先清掉舊提示 |
| userId != "" | 有輸入才送查詢 |
| url | 指定請求網址 |
| type:"post" | 指定請求方式 |
| userId: userId | 左邊是送出的欄位名稱；右邊是 JS 變數 |
| _token | 送出 CSRF token，配合 web 路由檢查 |
| success: function(msg) | 請求成功後取得回應內容；不是表示帳號一定可用 |
| msg.trim() == "exist" | 依老師約定，收到 exist 代表有重複 |
| .focus() | 把焦點移回帳號框 |

AJAX 是在目前頁面發出非同步請求，再更新部分畫面；不是由 view() 重新顯示整頁。
原碼沒有 error 回呼；沒有提示不一定就是成功，除錯要看 Network 的狀態與回應。

## 12. 實際新增帳號 store

### 12-1. 加入接收路由

在 admin + manager 的受保護群組內加入：
```php
Route::post("store", [ManagerController::class, "store"]);
```
其完整網址應是 /admin/manager/store。原筆記的 /manager/store 是老師另一種網址安排，不要與目前專案混用。

### 12-2. Controller 寫入資料

ManagerController.php 內加入：

```php
public function store(Request $req){
        // 新增物件
        $manager = new Manager();
        // $manager 為manager資料表
        // $manager->userId 為manager資料表中userId欄位
        // $req->userId 新增帳號網頁中所輸入的帳號
        $manager->userId = $req->userId;
        $manager->pwd = $req->pwd;
        // 將所輸入的資料存入manager資料表中
        $manager->save();

        // 通常新增完成要告知使用者已新增完成，這裡為了簡化流程，先暫時不處理
        // 路徑老師是打"/manager/list"，但我這邊的路徑是"/admin/manager/list"，應該這樣寫才符合我這邊的需求
        return redirect("/admin/manager/list");
    }
```

**原碼註解修正理解：$manager 是 Model 物件，不是 manager 資料表本身。**

| 步驟 | 發生什麼事 |
| --- | --- |
| new Manager() | 建立尚未儲存的 Model 物件 |
| ->userId、->pwd 賦值 | 將請求資料放進物件；此時還沒寫入 |
| save() | 將新紀錄寫入資料庫 |
| redirect(...) | 要求瀏覽器重新請求列表網址 |

此處是逐欄賦值，不是 create([...]) 的批次賦值；$fillable 不會替你驗證必填、長度或重複帳號。
原筆記尚未補入後端驗證，先用不重複的假帳號跑通流程。


### 12-3. 已驗證修正：避免模板攔截表單

`admin.js` 會執行：

```javascript
document.querySelectorAll('form.admin-form').forEach(initForm);
```

被選中的表單會被 `e.preventDefault()` 阻止送出，再顯示成功提示，最後執行 `location.href = form.dataset.back`。這段示範沒有把資料送到 Laravel；缺少 data-back 時還會跳到 `/admin/manager/undefined`。

**本次選擇保留 JS，將 class 移到外層 div：**

```blade
<div class="admin-card-body admin-form">
    <form action="/admin/manager/store" method="post">
        @csrf
        {{-- 原本欄位與按鈕放在此處，保留完整內容 --}}
    </form>
</div>
```

| 項目 | 確認事項 |
| --- | --- |
| 外層 div | class 是 admin-form，不是 admin-from |
| form | 移除 class="admin-form"，不是兩邊都加 |
| data-back | 只修正轉址，無法恢復被阻止的 POST，因此不是完整解法 |
| CSS | class 移動後一般後代選擇器仍可套用；若選擇器限定 form.admin-form，需另檢查 |
| edit 表單 | 同理將 admin-form 放外層，form 本身不要帶該 class |

更新檔案後重新整理再測試。已驗證：正常送往 store()、新增一筆、回到列表。`is_active` 核取方塊仍未由目前 store() 儲存。

### 13-3. Controller 查詢與更新

ManagerController.php 內新增：

```php
// 修改管理帳號
    public function edit(Request $req){
        // $req->id 中的id為路由/admin/manager/edit/{id}中的id，兩個名稱要一樣
        // 在manager資料表中尋找所帶進來的id這筆資料
        $manager = Manager::find($req->id);
        return view("admin.manager.edit", compact("manager"));
    }

    // 更新管理帳號
    public function update(Request $req){
        $manager = Manager::find($req->id);
        $manager->userId = $req->userId;
        $manager->pwd = $req->pwd;
        // 也可用$manager->save();
        // 通常要判斷更新的帳號是否已存在資料表中，這裡先省略
        $manager->update();
        return redirect("/admin/manager/list");
    }
```

| 方法 | 做什麼 |
| --- | --- |
| edit() | find 主鍵，傳 manager 給 View，顯示現有資料 |
| update() | 找同一筆、改屬性、保存更新，再回列表 |

find() 查不到為 null；原碼未處理此情況，不能直接對 null 讀寫。後續要補找不到時的回應與重複帳號驗證。

## 15. 登出：確認 → 請求 → 清除 Session → 登入頁

### 15-1. 登出路由

在既有 admin 群組內加入（原筆記行尾缺分號，這裡已補）：
```php
Route::get("logout", [AdminController::class, "logout"]);
```

### 15-2. Controller 移除登入狀態

AdminController.php 上方確認有：
```php
use Illuminate\Support\Facades\Session;
```

在類別內加入：

```php
public function logout(){
        // 下面寫法等同於session()->forget("userId")
        Session::forget("userId");
        /* 清空所有session:
           Session::flush();
        */
```

| 寫法 | 差別 |
