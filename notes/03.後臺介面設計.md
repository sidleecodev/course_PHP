## 2. 拆出側欄

1. 把 home.blade.php 全部內容複製到 layout.blade.php。
2. 從 layout 剪下完整 `<aside>...</aside>`，放到 menu.blade.php。
3. layout 原本側欄位置改成 `@include("admin.menu")`。

老師的局部示意：

```blade
<body class="admin-body">
    <!-- ===== 側欄 =====
        php的引入檔案方式有4種，include, include_once, require, require_once  
    -->
    @include("admin.menu")
    ...
    ...
</body>
```

`@include`：引入另一個 Blade 模板。
原碼的 `...` 是省略標記，不是要貼入網站的內容。

PHP 的 include／require 不完全相同：引入失敗時的處理不同；_once 表示避免重複引入。本例使用 Blade 的 @include。

## 4. 內容改成插槽、首頁套用版型

### layout.blade.php

把 main 內的內容剪到 home，保留 layout 的 main 外層：

```blade
        <main class="admin-content">

        </main>
```


### home.blade.php

使用以下結構，將原 main 內容放進 content 區：

```blade
@extends("admin.layout")
@section("title", "首頁")
/* 
  此語法等同於
  @section("title")
  首頁
  @endsection
*/
@section("content")
(原內容)
@endsection
```

> 上面的 `(原內容)` 是替換位置。原筆記用 `/* ... */` 說明等價寫法；它在一般 Blade／HTML 中不是隱藏註解，不能把這段筆記說明當作可執行頁面原樣貼上。

| 指令 | 意思 |
| --- | --- |
| @extends("admin.layout") | 使用共用外框 |
| @section("title", "首頁") | 填入標題插槽 |
| @section("content") | 開始定義內容區 |
| @endsection | 結束內容區 |
| @yield("content") | 在外框輸出這個內容區 |

`@yield` 是版型插槽，不只是一般 PHP 變數。

## 5. 建立帳號列表控制器

終端機：
```bash
php artisan make:controller Admin/ManagerController
```
產生：`app/Http/Controllers/Admin/ManagerController.php`。
確認引入 `use App\Models\Admin\Manager;`。

老師筆記已把後續第 9 步的 paginate 更新回這裡；保留此版本，不把它改回 get：

```php
<?php

namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use App\Models\Admin\Manager;
use Illuminate\Http\Request;

class ManagerController extends Controller
{
    public function list(){
        // get: 取得全部資料，也可以用all -> Manager::all();
        // 將取得的資料以$list變數儲存
        // 此處Manager是一個資料表，在app\Models\Admin\Manager.php
 	$list = Manager::paginate(10);
	/*
	    原本是指令是這個，但後續要做分頁(9.)，所以改為上面這個，括號內為幾筆為一頁
            $list = Manager::get();
	*/
        // compact: 將資料渲染到admin.manager.list這個網頁（此時list還沒創建）
        // compact("list"): 這個list為上一行的$list，兩個名稱要一樣
        return view("admin.manager.list", compact("list"));
    }
}
```

- `Manager` 是 Model，對應 manager 資料表。
- `paginate(10)`：每頁 10 筆，回傳分頁物件。
- `get()`／`all()`：取得資料集合，本身沒有 links()。
- `compact("list")`：建立含 list 鍵與 $list 值的陣列。
- `view(..., compact(...))`：將資料傳入指定模板，並回傳畫面。

## 7. 新增列表路由與登入保護

檔案：`routes/web.php`。以新群組替換舊的同功能群組，不要重複貼上。
確認上方有：
```php
use App\Http\Controllers\Admin\ManagerController;
```

```php
Route::group(["prefix" => "admin"], function () {
    // 後臺會員登入
    Route::get("/", [AdminController::class, "index"]);
    // 表單送到後臺
    Route::post("login", [AdminController::class, "login"]);
    // 登入成功跳轉頁面，在跳轉之前先跑一次middleware，確保有登入過才跳轉頁面
    Route::get("home", [AdminController::class, "home"])->middleware("manager");

    // !!!主要新增這裡!!!
    Route::middleware("manager")->group(function(){
        // 網址: /admin/manager
        Route::prefix("manager")->group(function(){
            // 網址: /admin/manager/list
            Route::get("list", [ManagerController::class, "list"]);
        });
    });
});
```

外層 admin + 內層 manager + list → /admin/manager/list。
`middleware("manager")`：先經過第一份筆記的登入檢查。

## 8. 選單亮起、列表顯示資料

### menu.blade.php：目前頁面的選單高亮

首頁：

```blade
<!-- 執行?的左邊，如果是就執行class，不是就執行：右邊的部分 -->
<a href="/admin/home" {!! Request::is('admin/home') ? "class='active'" : ''!!}><i class="fa fa-tachometer-alt"></i> Home</a>
```

帳號管理：

```blade
<a href="/admin/manager/list" {!! Request::is('admin/manager/*') ? "class='active'" : '' !!}><i class="fa fa-user-shield"></i> 帳號管理</a>
```

- `Request::is(...)`：判斷目前路徑，* 可匹配路徑。

## 9. 分頁、總筆數

### 9-1. 設定分頁樣式

檔案：`app/Providers/AppServiceProvider.php`。

```php
<?php

namespace App\Providers;

use Illuminate\Pagination\Paginator;
use Illuminate\Support\ServiceProvider;

class AppServiceProvider extends ServiceProvider
{
    /**
     * Register any application services.
     */
    public function register(): void
    {
        //
    }

    /**
     * Bootstrap any application services.
     */

    // 主要修改這邊
    public function boot(): void
    {
        Paginator::useBootstrap();
    }
}
```

`boot()` 執行設定；`Paginator::useBootstrap()` 指定 Bootstrap 分頁模板，不會幫你載入 Bootstrap CSS。依老師的版型測試，不在本筆記改換 API。

### 9-2. 列表底部顯示分頁

檔案：`list.blade.php`。

```blade

        <span>共 <b data-total>2</b> 筆</span>
```

`$list->links()`：產生分頁按鈕，需要控制器使用 paginate()。
如果出現 Collection::links does not exist，先檢查是否仍用 get()／all()。

### 9-3. 控制器附加總筆數

替換 ManagerController 的列表內容，保留其他方法：

```php
<?php

namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use App\Models\Admin\Manager;
use Illuminate\Http\Request;

class ManagerController extends Controller
{
    public function list(){
        // get: 取得全部資料，也可以用all -> Manager::all();
        // 將取得的資料以$list變數儲存
        // 此處Manager是一個資料表，在app\Models\Admin\Manager.php
        $list = Manager::paginate(10);
	// !!主要修改這邊
        // 計算總筆數
        $total = Manager::count();

        // compact: 將資料渲染到admin.manager.list這個網頁
        // compact("list"): 這個list為上一行的$list，兩個名稱要一樣
        return view("admin.manager.list", compact("list", "total"));
	// 到這邊!!
    }
}
```

- `Manager::count()`：目前整張 manager 表的總筆數。
- `compact("list", "total")`：將兩個變數傳給 View。

> 原筆記漏了 View 的對應修改：畫面仍固定寫 2，不會自動顯示 $total。要顯示動態總數，應把數字位置改為 `{{ $total }}`。這是功能補充，不是錯字，所以未擅自改動上面的原碼。
