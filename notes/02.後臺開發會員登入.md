# 02. 後臺開發會員登入

> 目標：顯示登入頁 → 接收帳號密碼 → 查資料 → 記錄登入狀態 → 保護後臺。
> 依老師筆記順序整理；保留原程式。說明以本文件正文為準，原程式內部分註解不夠精確。
> 前置：已建立 Laravel 專案、設定 .env 連線，並在 phpMyAdmin 建立 project1151013。
> 本份是課堂練習，不可直接部署：明碼密碼、輸入驗證與 Session 安全仍待後續補強。

## 0. 啟動網站

終端機必須位於含 artisan 檔案的專案根目錄。

```bash
php artisan serve
```

保持執行；Ctrl + C 停止。其他指令使用另一個終端機。

## 1. 建立控制器

```bash
php artisan make:controller Admin/AdminController
```

產生：`app/Http/Controllers/Admin/AdminController.php`。

## 2. 控制器回傳登入畫面

修改上面的控制器：

```php
<?php

namespace App\Http\Controllers\Admin;

use App\Http\Controllers\Controller;
use Illuminate\Http\Request;

class AdminController extends Controller
{
    public function index(){
        return view("admin.login");
    }
}
```

- `namespace`：類別所在的命名空間。
- `use`：引入名稱，讓程式可使用簡短類別名稱；不是建立物件。
- `extends Controller`：繼承 Controller 的功能。
- `public function index()`：定義可被外部呼叫的方法。
- `return view("admin.login")`：回傳登入模板的畫面。
- `admin.login` 對應 `resources/views/admin/login.blade.php`。

## 3. 設定登入頁路由

檔案：`routes/web.php`。

```php
Route::get("/admin",[AdminController::class, "index"]);
```

確認檔案上方有：
```php
use App\Http\Controllers\Admin\AdminController;
```
意思：收到 GET /admin，呼叫 AdminController 的 index()。
`::class` 取得完整類別名稱，不會立刻執行控制器。

## 4. 建立登入 View

建立：`resources/views/admin/login.blade.php`。
貼入老師提供的 login.html，修改 CSS、JS 路徑。
Laravel 正常設定下，網址的公開資源由 public 目錄提供；不要把 public 寫進資源網址。

### 4-1. 修改表單

```blade
<form action="/admin/login" method="post">
            @csrf
            <!-- 權杖，安全性起見加入的 -->
            <div class="form-group">
                <label class="form-label" for="userId">帳號</label>
                <!-- 修改為userId -->
                <div class="input-icon-wrap">
                    <i class="fa fa-user-shield icon"></i>
                    <input type="text" id="userId" name="userId" class="form-control" required autofocus value="{{ old('userId')}}"/>
		<!-- value="{{ old('userId')}}"是保留輸入錯誤的帳號值，密碼那邊也可以改，但通常不保留 -->
                </div>
            </div>
            <div class="form-group">
                <label class="form-label" for="pwd">密碼</label>
                <div class="input-icon-wrap">
                    <i class="fa fa-lock icon"></i>
                    <input type="password" id="pwd" name="pwd" class="form-control" required />
                    <!-- 修改為pwd -->
                    <span class="pw-toggle" onclick="togglePw('pwd',this)"><i class="fa fa-eye"></i></span>
                </div>
            </div>
            <div class="form-group">
                <label class="form-check"><input type="checkbox" name="remember" value="1" /> 記住我</label>
            </div>
            <button type="submit" class="btn btn-primary btn-block"><i class="fa fa-sign-in-alt"></i> 登入後台</button>
        </form>
```

| 寫法 | 用途 |
| --- | --- |
| action="/admin/login" | 表單送到這個網址 |
| method="post" | 使用 POST 送出 |
| name="userId"／name="pwd" | 後端取得欄位值的名稱 |
| id="userId"／id="pwd" | 給 label、CSS、JS 等定位元素 |
| @csrf | 產生 CSRF 權杖欄位，配合框架檢查 |
| old('userId') | 取回先前保留的輸入 |
| required | 瀏覽器端必填，不等於後端驗證 |
| type="password" | 隱藏畫面上的字元，不等於加密儲存 |

「記住我」目前只有 checkbox；本筆記尚未實作記住登入的功能。
開啟：`http://127.0.0.1:8000/admin`。此時應看得到登入頁。

### 4-2. 顯示錯誤訊息

同一份 login.blade.php，修改標題區：

```blade
 	<div class="auth-title">
            <h2>後台管理系統</h2>
            @if($errors->has("msg"))
                <div class="text-danger">
                    {{ $errors->first("msg")}}
                </div>
            @endif
        </div>
```

`@if`、`@endif` 是 Blade 指令，不是「所有 @ 都呼叫 PHP」。
`$errors->has("msg")` 檢查訊息；`first("msg")` 取出第一則。
`{{ ... }}` 輸出內容，預設會做 HTML 跳脫。

## 5. 處理登入、轉址、後臺保護

### 5-1. 接收 POST

在 routes/web.php 加入：

```php
Route::post("/admin/login",[AdminController::class, "login"]);
```

控制器保留原 namespace 與 use，加入登入邏輯。以下是 class 區段，不是完整檔案：

```php
class AdminController extends Controller
{
    public function index(){
        return view("admin.login");
    }

    // 主要修改這段
    // 這邊是取得送過來的資料
    /* $req是變數，可自取
       Response：回應給使用者
       Request：使用者送出的請求，包括送出資料，點選超連結
    */
    public function login(Request $req)
    {
        // ->相當於"的"
        // 來自於表單的name(userId跟pwd)
        // 左邊名稱自取，右邊是表單名稱
        $userId = $req->userId;
        $pwd = $req->pwd;

        // 取得帳號密碼，並把它帶進來
	// 注意有沒有出現use App\Models\Admin\Manager;
        $manager = (new Manager())->getManager($userId, $pwd);
        // 如果帳號密碼不對，或是空的
        if (empty($manager)) {
            /*
                back:回到上一頁
                withInput: 保留上一頁所輸入的資料
                withErrors: 回傳錯誤訊息
                msg: 自己定義的名稱
            */
            return back()->withInput()->withErrors(["msg" => "帳號或密碼錯誤"]);
        } else {
            // 帳號+密碼存在(登入成功)
            // 將帳號暫存在伺服器，名稱為userId，值為所輸入的帳號
            session()->put("userId", $userId);
            // redirect: 轉址
            return redirect("/admin/home");
        }
    }
}
```

另外確認控制器上方有：
```php
use App\Models\Admin\Manager;
```

| 寫法 | 用途 |
| --- | --- |
| Request $req | Laravel 提供請求物件，$req 是參數名稱 |
| $req->userId | 從請求取出 userId 的值 |
| $userId = ... | 將右邊的值存進左邊變數 |
| new Manager() | 建立 Manager 物件 |
| ->getManager(...) | 呼叫這個物件的方法 |
| empty($manager) | 檢查查詢結果是否為空 |
| back() | 回到上一頁 |
| withInput() | 把輸入暫存，以便 old() 讀取 |
| withErrors(...) | 把錯誤訊息帶到下一個頁面 |
| session()->put("userId", $userId) | 以 userId 為鍵，記住這次登入帳號 |
| redirect("/admin/home") | 回應瀏覽器，請它轉到首頁 |

> 尚未建立 Manager 與資料表（第 6、7 步），現在不能完成登入測試。
> 未在密碼輸入框使用 old()，只是「畫面不回填密碼」。withInput() 未明確排除自訂欄位 pwd，不能視為保證沒有暫存密碼；此處保留老師原碼。

### 5-2. 登入成功後的首頁

原本的單一路由：

```php
Route::get("/admin/home", [AdminController::class, "home"]);
```

老師接著整理成群組；使用群組時替換原本同功能路由，不要重複加入：

```php
Route::group(["prefix" => "admin"], function () {
    // 後臺會員登入
    Route::get("/", [AdminController::class, "index"]);
    // 表單送到後臺
    Route::post("login", [AdminController::class, "login"]);
    // 登入成功跳轉頁面，在跳轉之前先跑一次middleware，確保有登入過才跳轉頁面
    Route::get("home", [AdminController::class, "home"])->middleware("manager");
});
```

`prefix => admin`：群組中的路徑前面加上 /admin。
`middleware("manager")`：先做登入檢查，通過才呼叫 home()。

> manager 別名要在下一段建立、註冊後才能使用。不要在中途測試受保護頁面。

控制器加入 home()；以下 `...` 是「略去既有內容」的筆記標記，不能照貼成 PHP 程式：

```php
class AdminController extends Controller
{
    ...
    ...
    public function home(){
        return view("admin.home");
    }

}
```

建立 `resources/views/admin/home.blade.php`，貼入老師的 index.html，修改 CSS、JS 路徑。

### 5-3. 建立 Middleware

只放一個登入畫面並不能阻止別人直接輸入後臺網址。
終端機：
```bash
php artisan make:middleware CheckManager
```
產生：`app/Http/Middleware/CheckManager.php`。

```php
<?php

namespace App\Http\Middleware;

use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

class CheckManager
{
    /**
     * Handle an incoming request.
     *
     * @param  Closure(Request): (Response)  $next
     */
    public function handle(Request $request, Closure $next): Response
    {
	// 主要新增這段
        if(empty(session()->get("userId"))){
            return redirect("/admin");
        }
        return $next($request);
    }
}
```

- Session 沒有 userId：回到 /admin。
- 有 userId：`$next($request)` 繼續往下一個處理步驟。
- 這裡檢查的是課堂版登入狀態，不是完整角色權限管理。

### 5-4. 註冊 Middleware 別名

檔案：`bootstrap/app.php`。這是「註冊中介層」，不是「註冊會員」。

```php
<?php

use App\Http\Middleware\CheckManager;
use Illuminate\Foundation\Application;
use Illuminate\Foundation\Configuration\Exceptions;
use Illuminate\Foundation\Configuration\Middleware;

return Application::configure(basePath: dirname(__DIR__))
    ->withRouting(
        web: __DIR__.'/../routes/web.php',
        commands: __DIR__.'/../routes/console.php',
        health: '/up',
    )
    // 主要修改這段
    ->withMiddleware(function (Middleware $middleware): void {
        $middleware->alias([
            "manager" => CheckManager::class
        ]);
    })
    ->withExceptions(function (Exceptions $exceptions): void {
        //
    })->create();
```

`"manager" => CheckManager::class`：讓路由可用 manager 指向 CheckManager。
既有專案若還有其他設定，保留它們，只整合老師指定的部分。

### 5-5. Session 設定

檔案：`config/session.php`。

```php
'expire_on_close' => env('SESSION_EXPIRE_ON_CLOSE', true),
```

依老師設定將預設值改為 true。
`env('名稱', 預設值)`：讀取環境值，沒設定才採用預設值。
true 表示 Cookie 隨瀏覽器工作階段結束而到期；不是關閉分頁立刻登出，瀏覽器還原功能也可能保留 Cookie。

## 6. 建立 Manager Model

```bash
php artisan make:model Admin/Manager
```

產生：`app/Models/Admin/Manager.php`。

```php
<?php

namespace App\Models\Admin;

use Illuminate\Database\Eloquent\Model;

class Manager extends Model
{
    // timestamps = false: 表示不要用Laravel硬塞的兩個時間欄位created_at及updated_at(預設會有這兩個欄位，但我們用不到)
    public $timestamps = false;
    // 資料表名稱
    protected $table = "manager";
    // 主鍵名稱，單引號雙引號都可以
    protected $primaryKey = 'id';
    // manager資料表中的欄位名稱
    // 程式用得到的欄位寫出來就好，用不到就不用寫
    // 正常來說不需要id，幾乎都是唯一，寫上是方便處理
    protected $fillable = ["id", "userId", "pwd"];

    // 只負責查資料，並回傳給controller，並沒有確認資料內容
    // string不必加，只是這邊會出現小提示，加上去只是要忽略提示而已
    public function getManager(string $userId, string  $pwd){
        /*
            self: manager這個資料表
            first(): 取第一筆資料
            下列語法= SELECT * FROM manager WHERE userId = xxx AND pwd = xxx LIMIT 1
        */
        // ""中表示欄位 
        $manager = self::where("userId", $userId)->where("pwd", $pwd)->first();
        return $manager;
    }
}
```

**正確觀念（原碼註解若不同，以這裡為準）：**

| 寫法 | 意思 |
| --- | --- |
| Manager extends Model | Manager 是模型類別，不是資料表本身 |
| $timestamps = false | 停用自動維護 created_at、updated_at，不會自動刪除欄位 |
| $table = "manager" | 指定對應的資料表 |
| $primaryKey = 'id' | 指定主鍵欄位 |
| $fillable | 允許批次賦值的欄位，不是「可查詢欄位」清單 |
| string $userId | 參數型別宣告，不是為了關掉提示 |
| self:: | 指向目前的類別 Manager |
| where("userId", $userId) | 條件：userId 欄位等於變數的值 |
| ->where("pwd", $pwd) | 再加上一個 AND 條件 |
| first() | 取得第一筆 Model，沒有符合資料則回傳 null |
| return $manager | 把查詢結果交回控制器 |
