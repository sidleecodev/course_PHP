PHP、Composer、Laravel 入門筆記
============================

所需工具：
VS Code 擴充套件安裝
Beauty、Auto Close Tag
Laravel goto view、Laravel goto component、Laravel goto Controller

用途：協助排版、補齊標籤、跳到相關檔案；不影響 Laravel 是否能執行。

一、工具分工
PHP：後端程式語言。
Composer：安裝、更新 PHP 套件，處理套件間的依賴。
Laravel：PHP 網站開發框架，提供路由、資料庫操作、登入驗證等功能。
Artisan：Laravel 的指令工具，用來啟動網站、建立控制器等。
XAMPP：本機開發工具組，包含 Apache、PHP、資料庫等。


二、建立專案（首次執行）
先安裝 PHP 與 Composer
在 VS Code 開啟終端機，切換到要存放專案的資料夾，輸入：

composer create-project laravel/laravel project1151013

意思：使用 Laravel 專案範本，建立 project1151013 資料夾。
project1151013 是自訂的專案資料夾名稱。

接著進入專案資料夾：
cd project1151013

以下所有 php artisan 指令，都在含有 artisan 檔案的專案根目錄執行。
VS Code 也可直接開啟 project1151013，再開終端機。


三、啟動網站（每次開發時執行）
php artisan serve

意思：啟動 Laravel 的本機開發伺服器
瀏覽器開啟終端機顯示的網址，通常是http://127.0.0.1:8000

終端機保持執行；Ctrl + C 停止網站。
要輸入其他指令，新增另一個終端機，並確認位於專案根目錄。


四、建立資料庫、設定連線
【先建立空資料庫】
1. 開啟 XAMPP，啟動 Apache、MySQL。
2. 瀏覽器開啟 http://localhost/phpmyadmin。
3. 新增資料庫，命名為 project1151013。（名稱與DB_DATABASE要相同）

Apache 提供 phpMyAdmin 網頁；MySQL 提供資料庫服務。
使用 php artisan serve 開啟 Laravel 網站，不需要靠 Apache。

【再修改專案根目錄的 .env】
.env 是環境設定檔；以下設定只負責連線，不會建立資料庫。

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=project1151013
DB_USERNAME=root
DB_PASSWORD=

DB_CONNECTION：資料庫連線類型。
DB_HOST：資料庫主機，127.0.0.1 表示自己的電腦。
DB_PORT：資料庫連接埠，需符合實際設定，通常為 3306。
DB_DATABASE：實際建立的資料庫名稱，必須完全一致。
DB_USERNAME／DB_PASSWORD：資料庫帳號／密碼，依實際設定填寫。
DB_PASSWORD= 表示密碼空白。

（補充：需要建立資料表時就執行下方指令）
需要建立 Laravel 預設資料表時，執行：
php artisan migrate

migrate：依專案中的 migration（資料表結構定義）建立或修改資料表。
「建立空資料庫」與「建立資料表」是不同步驟。


五、Session、Queue、Cache（修改 .env）
SESSION_DRIVER=file
SESSION_LIFETIME=120
SESSION_ENCRYPT=false
SESSION_PATH=/
SESSION_DOMAIN=null

QUEUE_CONNECTION=sync

CACHE_STORE=file

Session：記住使用者狀態，例如登入資訊。
  SESSION_DRIVER=file：Session 資料存成伺服器上的檔案。
  SESSION_LIFETIME=120：閒置有效時間為 120 分鐘。
  SESSION_ENCRYPT=false：不另外加密儲存的 Session 資料。
  SESSION_PATH=/：Session Cookie 適用於網站的所有路徑。
  SESSION_DOMAIN=null：使用預設的 Cookie 網域範圍。

Queue：安排工作，例如寄信。
  QUEUE_CONNECTION=sync：工作立即執行，適合目前的入門練習。
  原筆記 QUEUE_CONNECTION=file 已修正；file 不是內建佇列連線。

Cache：暫存結果，減少重複計算或查詢。
  CACHE_STORE=file：快取存成檔案。


六、時區與 Session 詳細設定
【config/app.php：使用台灣時區】
'timezone' => 'Asia/Taipei',

影響 Laravel 的日期時間處理，不會修改 Windows 系統時區。

【config/session.php：保留本筆記指定的設定】
'lifetime' => (int) env('SESSION_LIFETIME', 120),
'expire_on_close' => env('SESSION_EXPIRE_ON_CLOSE', true),

env('名稱', 預設值)：讀取環境設定，未設定時使用預設值。
(int)：將讀到的值轉成整數。
lifetime：讀取 .env 的 SESSION_LIFETIME，未設定則為 120 分鐘。
expire_on_close：讀取 SESSION_EXPIRE_ON_CLOSE，未設定則使用 true。
true：Cookie 隨瀏覽器工作階段結束而到期；不是關掉分頁就登出。
瀏覽器還原工作階段可能保留 Cookie，不能當成保證登出的機制。
注意：Laravel 官方預設通常為 false；此處保留課堂筆記的 true。
修改既有設定行即可，不要新增重複的設定鍵。

（AI自行新增）
修改設定後，若未生效，可在專案根目錄執行：
php artisan config:clear


七、建立首頁：路由 → 控制器 → View
路由：決定網址要交給誰處理。
控制器：處理請求，決定回傳什麼。
View：網頁模板，負責顯示畫面。

【1. 建立控制器】
輸入：
php artisan make:controller Front/IndexController

就會產生檔案：
app/Http/Controllers/Front/IndexController.php

檔案完整範例（在這份檔案中輸入以下程式碼，前兩行是AI添加的）：
<?php

namespace App\Http\Controllers\Front;

use App\Http\Controllers\Controller;

class IndexController extends Controller
{
    public function index()
    {
        return view("front.index");
    }
}

index()：控制器中的方法，名稱由自己決定。
return view("front.index")：回傳 front 資料夾中的 index 模板。
(AI添加)保留產生檔案的 namespace、use，不要只貼上 class 部分覆蓋整份檔案。

【2. 建立 View】
resources/views 是「網頁模板目錄」，不是網站公開根目錄。
於此新增 front 資料夾，再建立：
resources/views/front/index.blade.php

檔案內容先輸入：
首頁

Blade 是 Laravel 的模板系統，可在 HTML 中使用變數與條件等功能。
view("front.index") 對應 resources/views/front/index.blade.php。
點號表示資料夾層級；呼叫 view() 不用寫 .blade.php。

【3. 設定路由】
修改 routes/web.php：
<?php

use App\Http\Controllers\Front\IndexController;
use Illuminate\Support\Facades\Route;

Route::get('/', [IndexController::class, "index"]);

Route::get：設定 GET 請求的路由，例如在瀏覽器開啟頁面。

'/'：首頁路徑。
IndexController::class：指定控制器，取得 IndexController 的完整類別名稱。
"index"：指定控制器的 index() 方法。
(AI添加)若原本已有首頁 Route::get('/')，改掉原本那行，避免重複設定。

【4. 測試】
確認 php artisan serve 正在執行，開啟它顯示的網址並重新整理。
通常為 http://127.0.0.1:8000，頁面應顯示「首頁」。
流程：開啟 / → 路由找到 index() → 控制器回傳 View → 顯示「首頁」。


八、放入 CSS、JavaScript
將會使用的 css、js 資料夾複製到：
project1151013/public

public 才是網站對外公開的目錄；resources/views 是模板目錄。
例如：
public/css/allcss.css
public/js/main.js


九、每次重新開發的最短流程
1. VS Code 開啟 project1151013。
2. 需要資料庫時，啟動 XAMPP 的 MySQL。
   需要 phpMyAdmin 時，另啟動 Apache。
3. 專案終端機執行 php artisan serve。
4. 瀏覽器開啟終端機顯示的網址。

建立專案、資料庫、控制器，以及各項設定，不必每次重做。
