## 1. 建表：沿用已有資料

老師筆記的欄位與型別如下；已有表就核對欄位，不用重建。原稿沒列主鍵、自動遞增、預設值或資料庫外來鍵約束的建表設定；下方的欄位對應是 Model 的查詢規則，不代表資料庫已建立約束。

| 表 | 用途 | 欄位 |
| --- | --- | --- |
| `product_type` | 產品類別 | `id INT`、`title VARCHAR(20)` |
| `product_label` | 產品標籤 | `id INT`、`label VARCHAR(10)` |
| `product_photo` | 產品圖片 | `id INT`、`productId INT`、`photo VARCHAR(30)`、`createTime TIMESTAMP` |
| `product_spec` | 產品規格 | `id INT`、`productId INT`、`title VARCHAR(30)`、`content INT`、`createTime TIMESTAMP` |
| `product` | 產品 | `id INT`、`product_name VARCHAR(100)`、`title VARCHAR(200)`、`product_no VARCHAR(30)`、`price INT`、`sale_price INT`、`qty INT`、`content TEXT`、`create_time TIMESTAMP`、`label_id INT`、`type_id INT` |

## 2. 建立 Model

在專案根目錄執行，檔案已存在就跳過對應指令。原稿的 `Productlabel` 大小寫改為 `ProductLabel`，與類別及檔名一致。

```bash
php artisan make:model Product/Product
php artisan make:model Product/ProductPhoto
php artisan make:model Product/ProductSpec
php artisan make:model Product/ProductLabel
php artisan make:model Product/ProductType
```

| 從產品取得 | 關聯 | 欄位怎麼對 |
| --- | --- | --- |
| 類別 `types()` | `belongsTo` | `product.type_id → product_type.id` |
| 標籤 `labels()` | `belongsTo` | `product.label_id → product_label.id` |
| 圖片 `photos()` | `hasMany` | `product.id → product_photo.productId` |
| 規格 `specs()` | `hasMany` | `product.id → product_spec.productId` |

注意欄位拼法：產品的類別用 `type_id`，圖片、規格用 `productId`。以下保留老師提供的 Model；原稿標示未完的檔案，仍照原進度保留。

### Product.php

```php
<?php

namespace App\Models\Product;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;
use Illuminate\Database\Eloquent\Relations\HasMany;

class Product extends Model
{
    public $timestamps = false;
    protected $table = "product";
    protected $primaryKey = 'id';
    protected $fillable = ["id","label_id", "type_id", "product_name", "title", "product_no", "price", "sale_price", "qty", "content", "create_time"];

    public function types(): BelongsTo
    {
        return $this->belongsTo(ProductType::class, "type_id", "id");
    }

    public function labels(): BelongsTo
    {
        return $this->belongsTo(ProductLabel::class, "label_id", "id");
    }

    // 商品圖
    public function photos(): HasMany
    {
        return $this->hasMany(ProductPhoto::class, "productId", "id");
    }

    // 商品規格
    public function specs(): HasMany
    {
        return $this->hasMany(ProductSpec::class, "productId", "id");
    }
}
```

## 3. 接上後臺產品分類列表

`GET /admin/product/types/list` → `manager` 檢查登入 → `ProductTypeController::list()` → `ProductType::get()` 查 `product_type` → Blade 用 `$list` 顯示每筆 `title`。

### Controller

```bash
php artisan make:controller Admin/Product/ProductTypeController
```

```php
<?php

namespace App\Http\Controllers\Admin\Product;

use App\Http\Controllers\Controller;
use App\Models\Product\ProductType;
use Illuminate\Http\Request;

class ProductTypeController extends Controller
{
    public function list(){
        $list = ProductType::get();
        return view("admin.product.types.list", compact("list"));
    }
}
```

### 路由拆檔

在 `routes/web.php` 的既有後臺群組外載入 `routes/admin/product.php`。老師原寫法：

```php
include "admin/product.php";
```

本次實作用 `include __DIR__ . "/admin/product.php";` 明確從 `routes` 資料夾定位。兩種擇一。產品路由檔已帶 `admin/product` 前綴，不必再套另一層 `admin`。

下方保留老師所列的全部路由。**本次只需啟用並驗收 `list`**；其餘路由即使存在，也要等對應 Controller 方法完成。路由檔自行匯入 `Route`，因為 PHP 的 `use` 宣告不會從 `web.php` 傳給被包含的檔案。

```php
<?php

use App\Http\Controllers\Admin\Product\ProductTypeController;

use Illuminate\Support\Facades\Route;

// 後臺產品
Route::group(["middleware" => "manager", "prefix" =>"admin/product"], function(){
    // 產品類別
    Route::group(["prefix" => "types"], function(){
        Route::get("list", [ProductTypeController::class, "list"]);
        Route::get("create", [ProductTypeController::class, "create"]);
        Route::post("store", [ProductTypeController::class, "store"]);
        Route::get("edit/{id}", [ProductTypeController::class, "edit"]);
        Route::post("update", [ProductTypeController::class, "update"]);
        Route::post("delete", [ProductTypeController::class, "delete"]);
    });
});
```

## 4. 驗收

- 登入後從側欄開啟列表：網址是 `/admin/product/types/list`，選單有高亮；有分類時顯示 `title`，無資料時顯示「目前無資料」。
- 登出後直接開啟同一個網址：由既有的 `manager` Middleware 擋下並導回登入頁。
- 在 phpMyAdmin 拿一筆 `product.id` 去對照圖片、規格的 `productId`。這能核對關聯預期會找到哪些資料；分類頁沒有呼叫 `photos()` 或 `specs()`，不能以分類頁正常開啟來證明關聯已在網頁驗證。
