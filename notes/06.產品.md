## 1. 建表：沿用已有資料

老師筆記的欄位與型別如下；已有表就核對欄位，不用重建。原稿沒列主鍵、自動遞增、預設值或資料庫外來鍵約束的建表設定；下方的欄位對應是 Model 的查詢規則，不代表資料庫已建立約束。

## 2. 建立 Model

在專案根目錄執行，檔案已存在就跳過對應指令。原稿的 `Productlabel` 大小寫改為 `ProductLabel`，與類別及檔名一致。

```bash

```

| 從產品取得 | 關聯 | 欄位怎麼對 |
| --- | --- | --- |
| 類別 `types()` | `belongsTo` | `product.type_id → product_type.id` |
| 標籤 `labels()` | `belongsTo` | `product.label_id → product_label.id` |
| 圖片 `photos()` | `hasMany` | `product.id → product_photo.productId` |
| 規格 `specs()` | `hasMany` | `product.id → product_spec.productId` |

注意欄位拼法：產品的類別用 `type_id`，圖片、規格用 `productId`。以下保留老師提供的 Model；原稿標示未完的檔案，仍照原進度保留。

### Product.php

```php
<?php

namespace App\Models\Product;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Relations\BelongsTo;
use Illuminate\Database\Eloquent\Relations\HasMany;

class Product extends Model
{
    public $timestamps = false;
    protected $table = "product";
    protected $primaryKey = 'id';
    protected $fillable = ["id","label_id", "type_id", "product_name", "title", "product_no", "price", "sale_price", "qty", "content", "create_time"];

    public function types(): BelongsTo
    {
        return $this->belongsTo(ProductType::class, "type_id", "id");
    }

    public function labels(): BelongsTo
    {
        return $this->belongsTo(ProductLabel::class, "label_id", "id");
    }

    // 商品圖
    public function photos(): HasMany
    {
        return $this->hasMany(ProductPhoto::class, "productId", "id");
    }

    // 商品規格
    public function specs(): HasMany
    {
        return $this->hasMany(ProductSpec::class, "productId", "id");
    }

    // 一個商品有多張圖，要取第一張圖出來當封面
    public function firstPhoto()
    {
        return $this->photos->first();
    }
}
```

```php
<?php

namespace App\Http\Controllers\Admin\Product;

use App\Http\Controllers\Controller;
use App\Models\Product\ProductType;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Session;

class ProductTypeController extends Controller
{
    public function list(){
        $list = ProductType::get();
        return view("admin.product.types.list", compact("list"));
    }

    public function create(){
        return view("admin.product.types.create");
    }

    public function store(Request $req){
        $types = new ProductType();
        $types->title = $req->title;
        $types->save();

        Session::flash("message", "已新增");
        return redirect("/admin/product/types/list");
    }

    public function edit(Request $req){
        $types = ProductType::find($req->id);
        return view("admin.product.types.edit", compact("types"));
    }

    public function update(Request $req){
        $types = ProductType::find($req->id);
        $types->title = $req->title;
        $types->update();

        Session::flash("message", "已修改");
        return redirect("/admin/product/types/list");
    }

    public function delete(Request $req){
        ProductType::destroy($req->id);
        Session::flash("message", "已刪除");
        return redirect("/admin/product/types/list");
    }
}
```

| 方法 | 責任 |
| --- | --- |
| `list()` | 查資料交給列表 |
| `create()` | 開新增表單 |
| `store()` | `new` 新物件、填值、`save()` 新增 |

## 4. 路由與側欄

在 `routes/web.php` 的既有後臺群組外載入產品路由。老師寫法及本輪明確定位寫法擇一，不重複引入。

```php
// 老師寫法
include "admin/product.php";

// 本輪定位寫法（與上面擇一）
include __DIR__ . "/admin/product.php";
```

### routes/admin/product.php

原稿漏掉的 Controller 引入已補齊。PHP 的 `use` 不會由 `web.php` 繼承到被包含的檔案。下方保留全部路由規劃；產品本身的 `store/edit/update/delete` 尚無對應實作，本次不操作。

### 共用刪除：網址、編號、按鈕

沿用後臺 layout 已有的 `doDelete(id, btn, url)`，不用再加一份。按鈕的第三個參數決定請求目的地；路由決定 Controller，Controller 使用的 Model 決定操作的表。第一個參數 `id` 只指定那張表裡哪筆資料。畫面列保留 `data-row`。

若分類仍被產品 `type_id` 引用而被成功刪除，產品不會自動選其他分類；此時讀 `types->title` 可能對 `null` 取值報錯。是否允許刪除也受資料庫約束影響，這份程式沒有提供自動處理。

```php
        $types = ProductType::get();
        $list = Product::with(["types", "labels", "photos"])->orderByDesc("id")->paginate(10);
        return view("admin.product.product.list", compact("types", "list"));
    }

    public function create(){
        $types = ProductType::get();
        $labels = ProductLabel::get();
        return view("admin.product.product.create", compact("types", "labels"));
    }
}
```

| 程式 | 用途 |
| --- | --- |
| `ProductType::get()` | 分類清單，供列表選單使用 |
| `Product::with(["types", "labels", "photos"])` | 預載產品的三種關聯；不是選取產品表裡的同名欄位 |
| `orderByDesc("id")` | 產品編號由大到小 |
| `paginate(10)` | 執行分頁查詢，一頁最多 10 筆；不再接 `get()` |
| `firstPhoto()` | 讀這筆產品的圖片集合，取第一個圖片物件；沒有圖回傳 `null` |
| `firstPhoto()->photo` | 從圖片物件取出檔名；不是再查另一張圖片 |

一筆產品有多張圖片，仍是一筆產品。老師沒有指定圖片排序，`firstPhoto()` 不表示可自行指定封面。
