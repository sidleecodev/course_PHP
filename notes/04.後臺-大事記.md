### 2-1. MileStoneType：一個類別有多筆大事記

另確認引入：

```php
use Illuminate\Database\Eloquent\Relations\HasMany;
```

```php
// 大事記類別
class MileStoneType extends Model
{
    public $timestamps = false;
    protected $table = "milestone_type";
    protected $primaryKey = 'id';
    protected $fillable = ["id", "label", "title"];

    public function milestone(): HasMany
    {
        // 每一個類別可能有多筆大事記
        return $this->hasMany(
            MileStone::class,
            "typeId", // 大事記資料表的外來鍵
            "id" // milestone_type的主鍵
        );
    }
}
```

### 2-2. MileStone：一筆大事記屬於一個類別

另確認引入：

```php
use Illuminate\Database\Eloquent\Relations\BelongsTo;
```

```php
// 大事記
class MileStone extends Model
{
    public $timestamps = false;
    protected $table = "milestone";
    protected $primaryKey = 'id';
    protected $fillable = ["id", "typeId", "years", "months", "title", "content", "createTime"];

    public function types(): BelongsTo
    {
        // typeId：milestone資料表的外來鍵
        // id：milestone_type的主鍵
        // 等同於 SELECT a.*, b.* FROM milestone a INNER JOIN milestone_type b ON a.typeId = b.id
        /*
        也可以用(DB要use Illuminate\Support\Facades\DB)
          DB::table("milestone as a")->selectRaw("a.*, b.*")->join("milestone_type as b")->get()
        或
          DB::table("milestone as a")->join("milestone_type as b")->selectRaw("a.*, b.*")->get()
        順序不影響
        DB：資料庫  table：資料表   join：inner join兩邊都有資料    selectRaw：查詢欄位 get：取全部資料
        selectRaw("a.*, b.*")也可以改用select("a.*", "b.*")
        */
        return $this->belongsTo(MileStoneType::class, "typeId", "id");
    }
}
```

### 2-3. 先理解設定與關聯

| 寫法 | 意思 |
| --- | --- |
| public $timestamps = false | 不自動維護 created_at、updated_at |
| protected $table | 指定操作的資料表，不建立資料表 |
| protected $primaryKey | 指定主鍵名稱，不替資料庫建立主鍵 |
| protected $fillable | 大量賦值的允許欄位，不是查詢欄位，也不會自動儲存 |
| milestone(): HasMany | 宣告這個方法回傳 HasMany 關聯物件；不是直接回傳資料陣列 |
| types(): BelongsTo | 宣告回傳 BelongsTo 關聯物件 |
| $this | 目前這個 Model 物件 |
| MileStone::class | 取得相關 Model 的完整類別名稱，不是資料表字串 |

兩個 Model 在同一 namespace，因此可直接使用彼此的類別名稱。

| 關聯 | 查哪邊？ | 對應欄位 |
| --- | --- | --- |
| 類別 → milestone() | 找這個類別底下的大事記 | milestone.typeId = 目前類別.id |
| 大事記 → types() | 找這筆大事記所屬類別 | milestone_type.id = 目前大事記.typeId |

例如：類別 id=2 是「活動」，三筆大事記的 typeId 都是 2，它們就同屬這個類別。**不是每筆大事記建立一個新的類別。**

教學補充，只用來理解兩種取值，不取代老師程式：

```php
// 假設已查得有效 Model：
$type->milestone;   // 這個類別底下的大事記集合
$item->types;       // 這筆大事記所屬的類別 Model；找不到可能為 null
```

關聯方法加括號是取得關聯查詢物件；以屬性方式存取會取得關聯資料。hasMany／belongsTo 不會因為定義了就立即將全部資料 JOIN 成同一張表。

### 2-4. 原 JOIN 註解需分開理解

上面保留老師原註解，但有兩點不能照字面理解：

1. `belongsTo()` 定義關聯，不等於立刻執行註解中的 INNER JOIN；取關聯資料時通常依關聯鍵另外查詢。
2. 原 `join("milestone_type as b")` 沒有提供 ON 條件，不是完整可執行的 JOIN 範例。

補充：若要實際表達原 SQL 的 JOIN，需寫出欄位對應：

```php
use Illuminate\Support\Facades\DB;

DB::table("milestone as a")
    ->join("milestone_type as b", "a.typeId", "=", "b.id")
    ->select("a.*", "b.title as typeTitle", "b.label as typeLabel")
    ->get();
```

原註解中的 `selectRaw("a.*, b.*")` 與 `select("a.*", "b.*")` 都保留在原 Model 區塊。兩表同名的 id、title 可能衝突；補充例子用別名區分。select 與 join 在這些簡單鏈式寫法可調整順序，不代表所有方法都能任意交換。

## 7. 儲存成功後顯示 SweetAlert

### 7-1. Session::flash 的角色

```php
Session::flash("message", "已新增");
```

message 是自行命名的 Session 鍵，已新增 是內容。flash 資料供目前及下一次請求使用，之後清除；不是因為讀取一次就立刻消失。

本例的用途：POST 儲存 → flash 暫存訊息 → redirect → 下一次 GET 列表讀到訊息並顯示。重新整理後通常不再出現。不同於登入狀態用 put 持續保存。

### 7-2. 載入 SweetAlert2

## 9. 路由整合：配合目前 admin 前綴與登入保護

前文完整網址版保留老師記法。若整合到現有專案，建議在原 admin 群組的 manager Middleware 保護區內加入下面片段；**不要同時貼完整網址版與群組版。**

```php
// 此片段放在既有 prefix("admin") 與 middleware("manager") 群組內。
// 與 prefix("manager") 的帳號管理網址群組並列，不放進該網址前綴。
Route::prefix("milestone")->group(function () {
    Route::get("list", [MileStoneController::class, "list"]);

    Route::prefix("types")->group(function () {
        Route::get("list", [MileStoneTypeController::class, "list"]);
        Route::get("create", [MileStoneTypeController::class, "create"]);
        Route::post("store", [MileStoneTypeController::class, "store"]);
        Route::get("edit/{id}", [MileStoneTypeController::class, "edit"]);
    });
});
```

Middleware 別名 manager 表示登入檢查，不等於網址前綴 manager；兩者要分清。

```bash
php artisan route:list --path=admin/milestone
```

| HTTP 方法與完整網址 | Controller 方法 | View／回應 |
| --- | --- | --- |
| GET /admin/milestone/list | MileStoneController::list | admin.milestone.list，動態資料待續 |
| GET /admin/milestone/types/list | MileStoneTypeController::list | admin.milestone.types.list |
| GET /admin/milestone/types/create | MileStoneTypeController::create | admin.milestone.types.create |
| POST /admin/milestone/types/store | MileStoneTypeController::store | 寫入後轉址類別列表 |
| GET /admin/milestone/types/edit/{id} | MileStoneTypeController::edit | admin.milestone.types.edit，View 待續 |
